# PennyPilot Project Repository

This repository contains the foundational dataset, data analytics report, and product documentation for **PennyPilot**, a FinTech product designed to make financial awareness effortless for irregular earners[cite: 1]. 

## Files in this Commit

### 1. `PRODUCT DOCUMENTATION_PENNYPILOT.pdf`
* Serves as the core product documentation developed for the Betechified PM Cohort[cite: 1].
* Outlines the primary problem statement: helping gig workers, traders, and freelancers manage unpredictable income against fixed expenses[cite: 1].
* Details the MVP features, including manual income/expense logging, savings envelopes, and a real-time "Survival Dashboard"[cite: 2].
* Defines product goals, user behaviour assumptions, technical constraints, and a phased rollout roadmap[cite: 1, 3, 4].

### 2. `FinTech.csv`
* The primary dataset backing the product analysis, containing over 32,000 individual user records.
* Includes 20 distinct data points per user, covering demographics (age, gender, education, region), employment status, monthly income and expenses, savings balances, credit scores, and loan details.

### 3. `FinTech ANALYTICS AND REPORT .docx`
* A comprehensive data analytics report deriving insights from the `FinTech.csv` dataset[cite: 6].
* Highlights key financial metrics, identifying an average monthly income of $4,028, average savings of $243,752, an average credit score of 575, and noting that 40% of the customer base utilizes loans[cite: 6].
* Translates data signals directly into actionable PennyPilot product decisions, such as introducing micro-savings for the under-30 demographic and debt-linked savings products for high earners[cite: 6].
